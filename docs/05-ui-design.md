# memoir 桌面端 UI 设计规范

> 简约 · 沉静 · 治愈。深蓝为底，浅青为光。为长时间读文字而设计。

---

## 1. 设计原则

**安静优先。** 界面上除了文字，其余元素都应「退到后面」。任何装饰如果会和正文争夺注意力，就去掉。

**一处光就够。** 全屏只允许一种发光——浅青色的边缘微光，出现在选中项、当前卡片、输入聚焦三处。其余地方一律无光。发光是稀缺资源，用多了就变成霓虹。

**不冻人。** 科技感来自秩序（栅格、细线、等距），不来自蓝紫渐变和玻璃拟态。所有色值饱和度压在 40% 以下。

---

## 2. 色板

| 语义 | 色值 | 用途 |
|---|---|---|
| `bg.base` | `#0A1018` | 窗口底色，最深的一层 |
| `bg.side` | `#0D1520` | 左侧导航栏 |
| `bg.panel` | `#111A28` | 右侧参数面板 |
| `bg.card` | `#141F30` | 卡片、列表行 |
| `bg.cardHover` | `#182638` | 行悬浮 |
| `line.hair` | `#1C2A3D` | 1px 分隔线、卡片描边 |
| `line.strong` | `#26374F` | 输入框、聚焦前描边 |
| `ink.primary` | `#E3EBF5` | 正文、标题 |
| `ink.secondary` | `#93A6BF` | 次要说明、时间戳 |
| `ink.tertiary` | `#5E7089` | 占位符、禁用态 |
| `accent.cyan` | `#6FD3D8` | 强调色：选中、按钮、链接 |
| `accent.soft` | `#3E8FA0` | 强调色的暗一档，用于描边 |
| `accent.glow` | `rgba(111,211,216,0.18)` | 微光，仅三处使用 |
| `state.warn` | `#C9A36B` | 提醒（低饱和琥珀） |
| `state.error` | `#C97B7B` | 错误（低饱和红） |

**禁止使用的颜色**：纯黑 `#000`、纯白 `#FFF`、任何饱和度 > 60% 的色、蓝紫渐变、彩色投影。

**对比度**：正文 `ink.primary` 对 `bg.base` 约 13:1，远超 WCAG AA。次要文字 5.4:1，达 AA。

## 3. 字体与排版

| 场景 | 字体栈 | 字号 / 行高 / 字重 |
|---|---|---|
| 界面标签 | Inter, "PingFang SC", "Microsoft YaHei UI" | 13/20 / 500 |
| 区块标题 | 同上 | 15/22 / 600 |
| 页面标题 | 同上 | 20/28 / 600 |
| **阅读正文** | "Source Han Serif SC", "Songti SC", Georgia, serif | 15/28 / 400 |
| 时间戳 / 元信息 | Inter 等宽数字（`font-variant-numeric: tabular-nums`） | 12/18 / 400 |
| 代码 / 路径 | "JetBrains Mono", Consolas | 12.5/20 / 400 |

**为什么正文用衬线**：长时间读自己的日记，无衬线会显得「像在看文档」，衬线更接近纸。UI 元素全部无衬线，形成对比。

**段落宽度**：主阅读区单行不超过 **68 个汉字**（约 720px），超过要分栏或缩进——这是这条界面的底线。

---

## 4. 空间与栅格

```
窗口 1280 × 800（最小 1024 × 680）
├─ 左侧导航   220px（固定）
├─ 主内容区   自适应（1280 时约 760px）
└─ 右侧面板   280px（固定，可折叠至 0）
```

- 基础单位 **4px**，间距只用 4/8/12/16/24/32/48
- 页面内边距：上 28 / 左右 32 / 下 24
- 卡片内边距：20
- 卡片间距：12
- 卡片圆角：**12px**；输入框与按钮圆角：**8px**；头像/圆点：圆形
- 描边统一 **1px**，从不用 2px 以上

---

## 5. 光效规则（唯一一条）

微光只出现在三处，别处一律没有：

| 位置 | 效果 |
|---|---|
| 左栏选中项 | 左侧 2px 竖条 `accent.cyan` + 该项背后 `accent.glow` 径向渐变（半径 60px） |
| 当前聚焦卡片 | 外侧 `0 0 0 1px accent.soft` + `0 0 16px accent.glow` |
| 输入框聚焦 | 描边转 `accent.cyan`，外发光 `0 0 12px accent.glow` |

除此之外：**没有 box-shadow 彩色投影，没有霓虹描边，没有渐变按钮。**

## 7. 区域组件划分

### 7.1 左侧导航栏（220px）

| 组件 | 规格 | 状态 |
|---|---|---|
| `NavLogo` | 高 56，左侧 24 内边距；文字「memoir」16/600 + 下方「记忆」12/次要色 | 默认 |
| `NavItem` × 5 | 高 44，左右内边距 16，图标 18×18 + 文字 13/500，间距 12 | 默认 / 悬浮(`bg.cardHover`) / 选中(竖条+微光+文字转白) |
| `NavDivider` | 1px `line.hair`，左右 16 外边距 | — |
| `NavStatus` | 高 36：8px 圆点（`#6FD3D8` 表示在线 / `#5E7089` 离线）+ 「模型已连接」12/次要色 | — |
| `ScalePattern` | 底部 160×160 的鱼鳞电路纹，opacity 0.06，仅描边无填充 | 装饰，不可交互 |

导航项顺序：记忆库 / 复盘记录 / 人格档案 / 设置 / 插件。

### 7.2 顶栏（主区顶部，高 56）

| 组件 | 规格 |
|---|---|
| `PageTitle` | 20/600，随页面切换 |
| `SearchBox` | 宽 240，高 32，圆角 8，左侧放大镜 14×14，占位符「搜索记忆…」 |
| `TopActions` | 右侧 1–2 个图标按钮（刷新 / 折叠右栏），32×32 圆角 8 |

### 7.3 主内容区

**记忆库页**

| 组件 | 规格 |
|---|---|
| `Composer` | 卡片，多行输入（最小高 88），底部工具条：类型下拉 + 标签输入 + 右侧「记下 ⌘↵」按钮 |
| `DayHeader` | 日期「2026-10-30」15/600 + 右侧「今天 12 条」12/次要色 |
| `MemoryRow` | 卡片高 64，内部**三块独立**，用 1px 竖线隔开（见下方规格） |
| `MemoryRow:hover` | 底色转 `bg.cardHover`，右侧浮出「删除」图标 |
| `EmptyState` | 居中 48px 图标 + 一行说明 13/次要色 |

**MemoryRow 三块结构**（时间 / 类型 / 内容各自独立，不挤在同一行文字流里）

```
┌──────────────────────────────────────────────────────────┐
│   22:06   │  ● 事件  │  桌面版打包完成，窗口能正常弹出      │
│  ← 64 →      ← 56 →     ←──────── 自适应 ────────→        │
└──────────────────────────────────────────────────────────┘
```

| 块 | 宽 | 规格 |
|---|---|---|
| `RowTime` | 64（右对齐） | 12.5 / `ink.tertiary` / 等宽数字 |
| `RowDivider` | 1px | 高 24，`line.hair`，垂直居中 |
| `RowKind` | 56 | 5px 圆点（类型色）+ 12 / `ink.secondary` |
| `RowDivider` | 1px | 同上 |
| `RowBody` | 自适应 | 15 / 衬线 / `ink.primary`，单行省略 |

三块都垂直居中。分隔线只做视觉切分，不改变行高。

**类型配色**（低饱和，只用于小圆点，不做背景填充）：

| 类型 | 色值 |
|---|---|
| 事件 | `#6FD3D8` 浅青 |
| 想法 | `#9C8FC4` 淡紫 |
| 情绪 | `#C9A36B` 淡琥珀 |
| 备注 | `#7B8CA6` 灰蓝 |

**复盘记录页**

| 组件 | 规格 |
|---|---|
| `ReviewList` | 左列 220px 日期列表，选中项同导航样式 |
| `ReviewBody` | 右侧正文区，五个小节：每个小节 = 标题（13/600 强调色）+ 正文（15/衬线/28 行高） |
| `ReviewMeta` | 底部一行：依据 N 条 · 模型名 · 语言，12/三级色 |

**人格档案页**

| 组件 | 规格 |
|---|---|
| `TraitCard` | 网格 2 列，卡片含：维度名 13/600 + 观察句 15/衬线 + 置信度条（`accent.soft` 填充，高 2px）+ 出处 12/三级色 |

**设置 / 插件页**

| 组件 | 规格 |
|---|---|
| `FormRow` | 标签 13/次要色在左（宽 120），输入框右对齐拉伸；行高 48 |
| `PluginCard` | 卡片：插件名 + 版本 + 钩子标签（圆角 4 的小胶囊，`line.hair` 描边）+ 启用开关 |

### 7.4 右侧参数面板（280px）

轻量化 = 只放「会影响当前页显示或行为」的东西，不放导航。

| 组件 | 规格 |
|---|---|
| `PanelSection` | 上下内边距 16，底部 1px 分隔 |
| `StatPair` | 左标签 12/次要色，右数值 13/等宽加粗 |
| `FilterChip` | 高 28 胶囊，选中：`accent.soft` 描边 + `accent.glow` 内发光 |
| `Select` | 高 32，圆角 8，右侧 ▾ |
| `CollapseHandle` | 8×40 竖条，悬浮显示，点击收起面板 |

右栏内容随页面变：

- 记忆库 → 今日统计 / 类型筛选 / 语言
- 复盘 → 日期范围 / 是否连模型
- 人格 → 置信度阈值 / 学习天数
- 设置 · 插件 → 空（面板自动收起）

## 8. 鱼鳞电路纹样（ScalePattern）

呼应鲸鱼娘人设的唯一装饰，规则很死：

- 只做**描边**，线宽 1px，`accent.soft`，整体 opacity **0.06**
- 图形语汇：弧形鳞片（半径约 22 的 1/4 圆弧）成排错位排列，弧线端点以小圆点（r=1.5）连接，像电路走线的焊点
- 出现位置：左栏底部（160×160）、空状态中央（120×120）
- **不出现**在卡片背景、正文区、按钮上

这不是「特效」，是纹理，应该像宣纸的纤维一样，只有凑近才看见。

---

## 9. 状态与动效

| 交互 | 时长 | 曲线 |
|---|---|---|
| 背景色变化（hover） | 120ms | ease-out |
| 描边/微光出现 | 180ms | ease-out |
| 页面切换 | 180ms | 淡入 + 位移 4px |
| 面板折叠 | 220ms | ease-in-out |

**禁止**：弹跳（bounce）、缩放超过 1.02、旋转、粒子、文字逐字动画。

---

## 10. 可访问性

- 键盘：Tab 顺序 = 导航 → 顶栏 → 主区 → 右栏；`⌘/Ctrl+Enter` 提交
- 焦点可见：所有可聚焦元素必须有 1px `accent.cyan` 焦点环，不允许 `outline: none`
- 正文对比度 ≥ 7:1，次要文字 ≥ 4.5:1
- 支持系统「减少动态效果」：全部过渡降为 0ms

## 12. 给 UI 绘图模型的提示词

```
设计一张桌面端应用界面稿，尺寸 1280×800，深色主题，简约沉静治愈风。

配色：基底 #0A1018 深蓝黑；面板 #111A28；卡片 #141F30；描边 #1C2A3D（1px 细线）；
正文 #E3EBF5；次要文字 #93A6BF；唯一强调色浅青 #6FD3D8。全部低饱和，无蓝紫渐变，无彩色投影。

布局：左侧固定导航栏 220px，含竖排五项「记忆库 / 复盘记录 / 人格档案 / 设置 / 插件」，
选中项左侧有 2px 浅青竖条与极淡径向微光；导航底部有一小块鱼鳞状细线纹样，透明度 6%。
中间主区：顶部 56px 顶栏（页面标题 + 搜索框），下方是记录输入卡片与按时间排列的记忆条目，
每个条目前有 3px 类型色竖条，正文使用衬线字体，行高宽松。
右侧 280px 参数面板：今日统计、类型筛选胶囊、语言下拉，卡片式分组，1px 分隔线。

质感：圆角 12px，细线描边，柔和微光只出现在选中项与输入框聚焦处。
整体像深夜书房，安静、克制、适合长时间阅读文字。不要霓虹、不要玻璃拟态、不要粒子特效。
```
