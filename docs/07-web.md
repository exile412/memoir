# Web 端（电脑 + 手机）

一套代码，浏览器直接访问。后端零第三方依赖——标准库 `http.server` 手写路由。

```bash
memoir web
```

启动后终端会打印两个地址：

```
本机   http://127.0.0.1:8765
手机   http://192.168.x.x:8765   （需同一 WiFi）
```

## 架构

```
memoir/web/
├── app.py        HTTP 服务、路由挂载、启动入口
├── routes.py     所有 API 与静态资源分发
└── static/
    ├── index.html   单页结构（侧栏 / 对话区 / 输入区 / 设置抽屉）
    ├── style.css    深色主题 + 响应式（860px 断点）
    └── app.js       原生 JS，无框架
```

前端不构建、不打包，改完刷新即可。后端与桌面版**共用同一套业务模块**：

```
storage / review / persona / llm / safety
        ↑                ↑
   memoir web       memoir gui
```

所以数据是同一份 `~/.memoir/memoir.db`，桌面端记的、网页端能看见，反之亦然。

## 接口

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/bootstrap` | 版本、统计、问候语、壁纸列表、分组 |
| GET | `/api/entries?q=&day=&kind=` | 列表 / 搜索 / 按天 |
| POST | `/api/entries` | 新建（`mode`: raw / polished / organized） |
| DELETE | `/api/entries/{id}` | 删除 |
| POST | `/api/polish` | 只润色，不保存 |
| POST | `/api/summarize` | 只整理，不保存 |
| GET / POST | `/api/review` | 读取 / 生成复盘 |
| GET | `/api/persona` | 人格档案 |
| POST | `/api/persona/distill` | 蒸馏新观察 |
| GET / POST | `/api/settings` | 模型与壁纸配置 |
| POST | `/api/model/test` | 探活模型 |
| GET | `/api/export` | 导出全量 JSON |
| GET | `/api/wallpapers` | 壁纸列表 |
| GET | `/api/wallpaper?id=` | 取壁纸图片 |

## 十个需求怎么落的

| 需求 | 实现 |
|---|---|
| 开屏 AI 先问 | 首页第一条气泡固定是「今天想要记录什么？」 |
| 壁纸引擎联动 | 自动探测 Steam 创意工坊 `431960` 目录，取每个项目的预览图作为背景候选；也可手动指定目录 |
| 文笔美化开关 | 输入栏「保存方式」下拉：原样保存 / 文笔美化 / AI 整理 |
| 自动元数据 | 时间戳由后端写入；标题由模型生成（可关） |
| 两种保存模式 | 「原样保存」= 你自己写的；「AI 整理」= 模型压缩成笔记。美化与整理都会把原文存进 `meta.original` |
| 代码识别 + 分组 | 前端检测代码特征，弹出分组询问；代码块渲染成等宽高亮块 |
| 跨端 | 服务监听 `0.0.0.0`，手机浏览器直接访问；860px 断点切成移动布局 |
| 模型接入 | 任意 OpenAI 兼容接口，三个字段配置 |
| 本地优先 | SQLite 单文件，`/api/export` 一键导出 |
| 长期检索 + 提醒 | 顶栏搜索走 FTS5；提醒用系统定时器调 `memoir once` |

## 使用说明

### 一、开壁纸引擎联动

1. 先确认 Wallpaper Engine 装过、且订阅了壁纸（创意工坊目录里要有东西）
2. 打开设置抽屉 → 壁纸区，会自动列出创意工坊里的壁纸缩略图
3. 点任意一张就套为背景，选择存在浏览器 `localStorage`，下次打开自动恢复
4. 想用自己的一堆图：在「壁纸目录」填一个文件夹路径，保存后点「刷新列表」

**限制**：只取静态图片（jpg/png/webp/gif）。Wallpaper Engine 的动态壁纸是视频/场景包，
浏览器没法直接当背景，这里退一步用它的预览图。要真动态背景得用 `<video>` 播 mp4 包，没做。

### 二、美化开关

输入栏左上角「保存方式」三个选项：

| 选项 | 行为 | 什么时候用 |
|---|---|---|
| 原样保存 | 一个字不动 | 记事实、写代码、不想被改 |
| 文笔美化 | 模型改表达，保留原意 | 口语记录想留得体面一点 |
| AI 整理 | 压缩成有条理的笔记 | 一大段流水账想理清楚 |

美化与整理都**不会丢原文**——原文存在条目的 `meta.original` 里，导出时能看到。

prompt 里明确写死：「不得添加原文没有的信息，不得拔高或美化事实」。

### 三、跨端访问

1. 电脑和手机连同一个 WiFi
2. 电脑上跑 `memoir web`
3. 手机浏览器打开终端里打印的那个 `http://192.168.x.x:8765`
4. 想更顺手的：Safari 点分享 →「添加到主屏幕」，Android Chrome 菜单里也有

**手机上怎么发送**：回车键发送（移动输入法会显示「发送」），Shift+回车换行。

**打不开的排查**：

| 现象 | 原因 |
|---|---|
| 手机连不上 | Windows 防火墙拦了 8765，去「允许应用通过防火墙」放行 Python |
| 能连但很慢 | 模型在电脑上跑，一次复盘几十秒，正常 |
| 换了 WiFi 地址变了 | 局域网 IP 会变，重新看终端打印的地址 |

## 已知限制

- **没有登录**：同一局域网内谁都能打开。只在自己家里用，别在公共 WiFi 上开
- **单进程**：服务和模型调用跑在一个进程里，长任务会占住一个线程（多线程服务，不影响别的请求）
- **移动端按钮**：发送按钮在部分手机浏览器上位置不稳定，改成回车发送；桌面端按钮正常
- **壁纸只支持静态图**
- **无离线缓存**：断网打不开（本来就是局域网服务）

## 和桌面版的关系

| | 桌面版 | Web 版 |
|---|---|---|
| 数据 | 同一个 `memoir.db` | 同一个 |
| 启动 | `memoir gui` / 双击 exe | `memoir web` |
| 手机 | ❌ | ✅ |
| 壁纸引擎 | ❌ | ✅ |
| 美化 / 整理 | ❌ | ✅ |
| 开销 | 12 MB exe | 一个 Python 进程 |

两个可以同时开——SQLite 的 WAL 模式支持并发读写。
